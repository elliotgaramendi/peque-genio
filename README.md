# [PequeGenio](https://elliotgaramendi.github.io/peque-genio/)

App educativa para peques de 2 a 3 años para aprender letras, emojis y números jugando con una interfaz simple, visual y divertida. 🎮✨

- Demo: [elliotgaramendi.github.io/peque-genio](https://elliotgaramendi.github.io/peque-genio/)
- Repositorio: [github.com/elliotgaramendi/peque-genio](https://github.com/elliotgaramendi/peque-genio)

![Captura de la web](./docs/web.png)

## Modos de juego

- 🔤 Letras Básico: mira la letra y tócala.
- 🦁 Emoji + Letra: mira el emoji y elige su letra inicial.
- 🔢 Números: reconoce números del 0 al 10.

## Cómo jugar

1. Elige un modo.
2. Escucha la guía de voz.
3. Toca la respuesta en los botones grandes.
4. Gana premios cada 5 aciertos. 🎁
